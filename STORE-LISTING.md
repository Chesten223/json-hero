## Detailed Description

**JSON Hero — The Clean JSON Viewer**

Tired of JSON formatter extensions that inject ads? So were we. JSON Hero is the beautiful, fast, privacy-respecting JSON viewer that puts you first.

**✨ Features**

🎨 **Gorgeous Syntax Highlighting** — Dark theme with color-coded keys, strings, numbers, booleans, and null values. Easy on the eyes.

🌳 **Interactive Tree View** — Click to expand/collapse any object or array. Type badges show you the structure at a glance.

🔍 **Instant Search** — Find any key or value across the entire JSON document. Real-time highlighting.

📊 **Stats at a Glance** — Total keys, nesting depth, and file size displayed in the toolbar.

📋 **Copy & Minify** — Copy formatted or minified JSON with a single click. No external tools needed.

🛡️ **Zero Permissions** — No special permissions. No access to your tabs. Only activates on JSON pages.

🔒 **Privacy First** — No analytics. No tracking. No data collection. Your JSON never leaves your browser.

**🆓 Free Forever**
- All features included
- No ads, no popups, no donate nag
- Open source on GitHub

**📋 How It Works**
1. Install JSON Hero
2. Navigate to any URL that returns JSON (APIs, endpoints, etc.)
3. JSON Hero automatically formats and displays it beautifully
4. Use the tree view, search, and copy buttons to explore

Also works as a popup formatter — click the extension icon and paste any JSON.

**The Story**
The most popular JSON formatter (1M+ users) started injecting ads and popups across all websites, including checkout pages. JSON Hero is our answer: clean, fast, and never compromised.

**Why Switch?**
- ✅ Manifest V3 compatible (won't break on Chrome updates)
- ✅ No ads, no tracking, no data collection
- ✅ Dark theme by default
- ✅ Tree view + search + stats (competitors lack these)
- ✅ Minimal permissions
