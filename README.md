# JSON Hero 🔮

> Beautiful JSON viewer for your browser. Zero ads. Zero tracking. Free forever.

## Why JSON Hero?

The most popular JSON formatter extensions (1M+ users) have started injecting ads and popups. JSON Hero is the clean, fast alternative.

## Features

- 🎨 **Beautiful Syntax Highlighting** — Dark theme with color-coded keys, strings, numbers, booleans, and null values
- 🌳 **Interactive Tree View** — Expandable/collapsible tree navigation with type badges
- 🔍 **Search** — Find any key or value instantly
- 📊 **Stats** — See key count, depth, and file size at a glance
- 📋 **Copy** — Copy formatted or minified JSON with one click
- 🛡️ **Zero Permissions** — No special permissions required. No data collected. Ever.

## Install

1. Download from [Chrome Web Store](#) (coming soon)
2. Navigate to any URL that returns JSON
3. That's it — JSON Hero automatically renders it beautifully

## Also Works In

- Paste JSON in the popup (click the extension icon)
- Works with `application/json`, `text/json`, and `application/ld+json`
